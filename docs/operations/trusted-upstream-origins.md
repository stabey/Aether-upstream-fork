# 可信上游字面 IP 白名单

管理员可以在执行请求的网关进程环境中配置：

```dotenv
AETHER_TRUSTED_UPSTREAM_ORIGINS=http://100.64.0.6:65500
```

容器部署必须将变量传入容器（仅修改宿主机 `.env` 而 Compose 没有引用并不生效），然后重建容器。多个条目用逗号分隔，所有执行节点分别配置并重启。

规则：

- 默认空，保留现有 URL 地址防护和 HTTP loopback 例外。
- 条目只能是 `http(s)://IP:port`，必须显式写端口。IPv6 写为 `https://[fd00::6]:443`。
- 精确匹配协议、IP、有效端口；允许该源下所有路径，包括模型列表和推理路径。
- 不支持域名、CIDR、通配符、路径、URL 凭据、query、fragment。非法配置整份拒绝，执行请求返回配置错误；错误不会回显配置内容。
- 白名单不作用于代理地址、隧道中继、OAuth 登录或远程附件下载的独立安全策略。
- 重定向默认关闭。显式开启时仍只允许同协议、同主机、同端口，且重新校验目标 URL；即使另一个目标也在白名单中，也不能跨源重定向。
- 模型获取被地址策略拒绝时显示“上游地址被安全策略拒绝”，不回显 URL、认证头或密钥。

## DNS 范围

本分支在 `522b97905` 中明确取消了 Provider DNS 地址过滤，以兼容 Fake-IP 和内网 DNS；这与字面 IP URL 检查是两套既有行为。本次不改变该兼容行为，也不新增 DNS 例外。白名单只匹配 URL 中的字面 IP，不能用域名或域名的解析结果命中白名单；字面 IP 无需 DNS 解析。H2C 直连同样在解析/连接前经过 URL 校验。隧道中继的 DNS 过滤保持不变。

因此该配置是精确的字面 IP URL 例外，不是所有 Provider 域名的全局 SSRF 防护。Provider 域名和代理本身仍须由可信管理员配置。

## 验证与回滚

配置示例只授权 `http://100.64.0.6:65500`；其他 IP、端口以及 HTTPS 均不匹配。验证模型获取时使用服务端存储的提供商凭据，避免在命令参数、终端或日志中输出密钥。

移除该变量并重启即可撤销例外。镜像回滚时恢复原 Compose 文件和原镜像标签；此变更没有数据库迁移。
